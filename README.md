# AIForce · nástroje / nástroje

**SK** · Malé nástroje AIForce pre Windows. Každý nástroj má vlastnú zložku, popis (`README_<MENO>.md`) a zadanie (`ZADANIE_<MENO>.md`), podľa ktorého vznikol. Súbory na stiahnutie nájdeš v **Releases** (vydania). Každé vydanie nesie súčty SHA256, ktoré si môžeš overiť príkazom `Get-FileHash <súbor> -Algorithm SHA256`.

**CZ** · Malé nástroje AIForce pro Windows. Každý nástroj má vlastní složku, popis (`README_<JMÉNO>_cz.md`) a zadání (`ZADANIE_<JMÉNO>_cz.md`), podle kterého vznikl. Soubory ke stažení najdeš v **Releases** (vydání). Každé vydání nese součty SHA256, které si můžeš ověřit příkazem `Get-FileHash <soubor> -Algorithm SHA256`.
